# Woning Geulwijk, renders

360-gradenpanorama's van de woonkamer van Johan, gerenderd in Blender vanuit een eigen model van de woning (json-data, script `build_scene.py`).
Bekijken: https://johan-gorter.github.io/woning-renders/

- `index.html`: de kijker (WebGL, geen bibliotheken). Slepen = rondkijken, scrollen of knijpen = zoom, 0 = beginstand.
- `keuken-dag.jpg`, `keuken-avond.jpg`, `bank-dag.jpg`, `bank-avond.jpg`: equirectangulaire panorama's van 4096 x 2048
  (variant `woonkamer-1` met `daglicht` en `schemer`, standpunten `woonkamer-keuken-360` en `woonkamer-tv-noord-360`).
